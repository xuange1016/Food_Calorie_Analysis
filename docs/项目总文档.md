# 基于机器视觉的食堂/外卖菜品识别与热量估算助手 - 项目总文档

## 1. 项目概述

本项目是《人工智能概论》课程设计项目，方向属于机器视觉应用。系统面向大学生日常饮食场景，用户上传一张食堂或外卖菜品图片后，系统使用图像分类模型识别食物类别，并根据本地营养信息表估算热量、蛋白质、脂肪和碳水化合物，最后给出简单饮食建议。

项目重点不是医学级精准营养计算，而是实现一个完整、可运行、可展示的人工智能应用流程，包括数据集准备、模型训练、图像预测、后端接口、前端展示和课程设计报告。

## 2. 功能需求

系统第一版支持以下功能：

- 用户上传或拍摄一张食物图片；
- 前端显示图片预览；
- 后端接收上传图片；
- 模型预测食物类别和置信度；
- 返回 Top-3 预测结果；
- 根据预测类别查询本地营养信息表；
- 展示热量、蛋白质、脂肪、碳水化合物；
- 根据营养信息给出简单饮食建议；
- Web 页面适配电脑端，并尽量兼容手机浏览器上传图片。

第一版暂不实现：

- 识别所有菜品；
- 多菜品分割；
- 食物重量估算；
- 医学级精确热量计算；
- 用户登录；
- 历史记录；
- 正式手机 App 上架。

## 3. 技术栈

## 5. 模型方案

项目采用 ResNet18 迁移学习。

基本思想：

- ResNet18 已经在大规模图像数据集上学习过通用图像特征；
- 项目将最后的分类层替换为 10 类食物输出；
- 使用 Food-101 筛选后的 10 类数据进行训练；
- 保存最佳模型用于 Web demo 推理。

训练参数：

| 参数 | 设置 |
| --- | --- |
| 模型 | ResNet18 |
| 图像尺寸 | 224 x 224 |
| 类别数 | 10 |
| Epoch | 8 |
| Batch size | 32 |
| 优化器 | Adam |
| 学习率 | 0.001 |
| 设备 | CUDA GPU |

## 8. 营养信息设计

营养信息存储在：

```text
backend/food_nutrition.json
```

每个类别包含：

- 中文展示名；
- 热量；
- 蛋白质；
- 脂肪；
- 碳水化合物；
- 单位；
- 饮食建议。

说明：

这些营养数值是平均估算值，单位为“每 100 克估算值”，不代表医学级精准测量。

```powershell
python training/evaluate.py --data-dir data/food101_10class --batch-size 32
```

## 12. 手机端扩展方案

第一版已经尽量兼容手机浏览器上传图片。后续如果需要变成手机安装包，可以采用两条路线：

### 路线一：WebView / Capacitor 打包

把当前 Web 页面封装成 Android 应用，模型仍由 Flask 后端推理。

优点：

- 改动较少；
- 能较快打包 APK；
- 适合课程设计后续扩展。

### 路线二：手机本地推理

将 PyTorch 模型转换为 ONNX 或 TensorFlow Lite，在手机本地完成推理。

优点：

- 可离线使用；
- 更接近真正移动端 AI 应用。

缺点：

- 模型转换和移动端部署难度更高；
- 不适合作为第一版课程设计主目标。

## 13. 项目总结

本项目完成了从 Food-101 数据集处理、ResNet18 迁移学习训练、模型测试、Flask 后端接口、Web 前端展示到营养建议输出的完整流程。系统测试集准确率达到 84.04%，能够满足课程设计演示需求。

项目仍有改进空间，例如扩展类别、增加多菜品识别、估算食物重量、优化移动端体验等。总体而言，该项目具有明确的应用场景、完整的 AI 流程和可运行的系统 demo，符合《人工智能概论》课程设计要求。
